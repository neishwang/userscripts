# userscripts

Collection de userscripts personnels (Tampermonkey / Violentmonkey / Greasemonkey).

## Installation

1. Installer une extension de gestion de userscripts :
   [Tampermonkey](https://www.tampermonkey.net/) ou [Violentmonkey](https://violentmonkey.github.io/)
2. Ouvrir le fichier `.user.js` souhaité en vue *raw* — l'extension propose l'installation automatiquement.
